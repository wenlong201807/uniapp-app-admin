# P2-05 录音媒体管理

`/media` 新增 AUDIO 类型筛选、时长/格式显示，以及转写状态、处理次数、脱敏错误代码。支持按所属用户或文件名查询；管理员删除录音释放配额，并级联删除转写、取消本服务正在处理的请求。删除前仍需确认。

管理接口仅返回转写元数据，不返回转写正文、供应商密钥、存储路径或公开播放 URL。普通用户令牌无法使用管理员媒体接口。用户可在客户端主动确认外部语音转文字；管理员不能代替用户确认。

删除不能保证清除供应商已收到的音频，外部留存由供应商政策决定。当前供应商未配置，READY 状态在端到端测试中用合成文字验证，并非真实语音识别验收。

`pnpm check`、12 项测试和 `pnpm build` 已通过。服务端所有权/管理员删除与级联测试见 [阶段十五](../../uniapp-app-server/docs/phase-fifteen.md)。Android/iOS/鸿蒙录音真机验收和鸿蒙原生录音适配仍待办。
