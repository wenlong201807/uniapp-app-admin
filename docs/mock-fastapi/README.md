状态：**已获授权自动分阶段实施，仅本地提交**。F01 已有本地基线，F02 基础导航与会话保护在管理端工作区，F05 技术方案已形成。三端写入和独立功能分支受当前环境限制；准确进度以 deliveries 记录为准。

## 诉求与约定

以本机 RuoYi-Vue3-FastAPI 的功能为参考，为“此刻”补齐管理平台能力。开发覆盖管理端、服务端及相关客户端功能；每个可独立验收的功能建立独立分支，涉及多个仓库时使用同名分支分别提交。

管理端保持 Vue 3、Element Plus、Pinia、Vite、TypeScript、Oxfmt 和 Oxlint；服务端沿用 NestJS、Prisma、MySQL、Redis；客户端沿用现有 uni-app Vue 3。目录名 mock-fastapi 表示参考功能梳理，不表示用模拟接口交付或将服务端迁移到 FastAPI。
