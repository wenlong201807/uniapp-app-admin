# RuoYi 基础功能对照与三端实施草案

状态：**梳理完成，待用户确认后实施**。本次仅新增文档，未修改三端业务代码、数据库或分支。

## 诉求与约定

以本机 RuoYi-Vue3-FastAPI 的功能为参考，为“此刻”补齐管理平台能力。开发覆盖管理端、服务端及相关客户端功能；每个可独立验收的功能建立独立分支，涉及多个仓库时使用同名分支分别提交。

管理端保持 Vue 3、Element Plus、Pinia、Vite、TypeScript、Oxfmt 和 Oxlint；服务端沿用 NestJS、Prisma、MySQL、Redis；客户端沿用现有 uni-app Vue 3。目录名 mock-fastapi 表示参考功能梳理，不表示用模拟接口交付或将服务端迁移到 FastAPI。

## 范围建议

将参考 README 的 **21 类内置功能全部纳入目标清单**，按依赖分阶段完成；复杂模块拆为独立功能分支。AI、插件、传输加密、构建器和代码生成也已列入，不因“基础功能”措辞而默认删除。是否全部实施仍待确认。

管理端实现管理功能；服务端负责真实数据、规则、权限与审计；客户端默认接入认证、个人中心、公告、授权文件和选用的 AI 对话等用户侧功能。移动端是否还承担管理员工作台，单独确认。

现有私人任务与个人影像继续工作。新增“全局任务管理”是当前产品的扩展需求，参考项目没有对应业务，列为可选项，不计入参考 21 类功能。
