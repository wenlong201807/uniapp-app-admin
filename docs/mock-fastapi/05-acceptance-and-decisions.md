# 验收标准与待确认决策

## “完整实现”的定义

一个功能完成需要同时满足：

1. 清单中选定页面和行为可用，包含异常、空状态、加载、验证与批量结果。
2. API 使用真实数据库/存储，身份、权限、数据范围与业务规则在服务端校验。
3. 数据迁移、种子、Swagger、配置说明、发布兼容及必要恢复方式齐全。
4. 功能相关仓库通过适当检查，并完成真实接口与页面联调；不以 Mock 成功作为交付。
5. 独立分支已经按最新要求完成本地提交，三仓变更可关联追溯；不推送、不合并。
6. 外部凭证、设备、平台限制如阻塞验收，明确保留未完成项，不宣称全部完成。

本轮梳理没有运行参考系统，不证明参考实现完全正确。测试目录是验收素材，不直接将 Python 测试当作 Nest 实现的测试。

## 检查与验证矩阵

| 范围         | 验证                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------ |
| 管理端       | pnpm check、pnpm build；相关页面浏览器实际操作，授权/直达/退出、表单/分页/导入导出、窄屏与键盘   |
| 服务端       | pnpm typecheck、pnpm build；迁移在隔离测试库应用；相关 E2E 及现有 auth/tasks/media/security 回归 |
| 客户端       | pnpm check、pnpm test；相关变更的 H5/App 资源构建，HarmonyOS 范围确认后构建；相关设备行为实测    |
| 组织权限     | 超级管理员、部门 A/B 的管理员、只读角色、多角色、普通用户、禁用用户、未登录                      |
| 数据范围     | 列表/详情/统计/导出/写入一致；跨部门、仅本人、批量混合授权、无角色、过期授权                     |
| 会话安全     | refresh 并发、旧 token 重放、退出/强退/禁用即时失效、网络错误、Redis 失败、迟到响应              |
| 文件         | 公开/受保护、ACL/引用、上传/下载/Range、失败恢复、回收/恢复/永久清理、配额、对账                 |
| 调度         | 多实例互斥、重启恢复、立即运行、错过/并发策略、失败日志、任务停用                                |
| 插件         | 从示例安装到启用/升级/失败/卸载/清理；依赖/菜单冲突；迁移状态；秘密与诊断脱敏                    |
| AI/加密/生成 | 真实 Provider/SSE/取消和用户隔离；篡改/轮换/重放；生成代码在隔离工程编译并运行                   |

不为文档或纯外观小改增加无意义测试。新权限、迁移、幂等和跨端行为有实质风险，应有针对性自动验证。必需检查通过后，不无理由重复扩大验证。

## 每阶段关键门槛

| 阶段        | 必须成立                                                                 |
| ----------- | ------------------------------------------------------------------------ |
| 认证与 RBAC | 管理身份与普通会话分离；服务端拒绝越权；最后管理员保护；旧私人接口兼容   |
| 系统管理    | 用户、角色、组织、菜单、字典、参数可用；导入导出真实；权限变化生效       |
| 日志与运维  | 可查真实成功/失败；强退即时；调度恢复；指标真实；清理有范围              |
| 文件        | 原有私人媒体不公开、不丢失；ACL/引用/配额一致；生命周期与对账可恢复      |
| 开发工具    | 生成 Vue3/Nest/TS 代码能构建；写路径和 DDL 策略已确认                    |
| 插件与 AI   | 示例插件生命周期可验收；真实模型流式可用；无密钥泄露；所选客户端平台通过 |

## 仍需确认的实施决策

下表保留原梳理的待细化事项。用户后续已授权自动完成全部阶段，常规实现按建议方案推进；不得据此重复请求开发授权。需要真实外部凭证或涉及既有私人数据边界时，明确实际限制。

| 编号 | 决策                    | 建议默认方案                                                       | 可选方案与影响                                                                         |
| ---- | ----------------------- | ------------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| D06  | 私人任务/影像的管理范围 | 保持私人 owner 隔离；参考文件功能另建清晰管理域                    | 增加全局任务/媒体查询与管理，需规定读写/删除权限及审计                                 |
| D07  | 管理登录持续状态        | 先内存 token，可记住账号，不保存密码                               | 刷新页面持久登录需选 cookie/BFF 或其他受控方案；复制“记住密码”需明确接受与现有策略差异 |
| D08  | 插件运行方式            | 可信插件发布期编译注册；已注册能力运行时启停；新增代码重建/重启    | 任意热装/热卸需额外隔离运行设计，不能以菜单开关代替                                    |
| D09  | 代码生成能力            | 预览/ZIP + 隔离建表和明确输出目录；适配 Nest/Prisma/Vue3/TS        | 首期禁用服务端写源码/DDL 或要求任意 SQL/本地生成；需明确参考功能适配边界               |
| D10  | AI 范围                 | 先确认首批 Provider、模型/凭证来源及是否提供客户端聊天             | 全供应商覆盖/增加图片生成；没有凭证可完成代码，但真实调用留待验收                      |
| D11  | 传输加密及客户端平台    | 先 off/optional，验证后 required；保留 HTTPS；先确定强制路径和平台 | 仅管理端加密或三端全部；H5/Android/iOS/HarmonyOS 密码学能力须逐一验证                  |
| D12  | 删除与保留策略          | 用户优先禁用/软删除，保留现有任务媒体；文件按引用/保留策略处置     | 硬删除用户会触发已有级联关系，不能按参考按钮直接删除现有业务数据                       |
| D13  | 协议、帮助、公开展示    | 功能可用，正文/品牌信息由用户确认                                  | 不复制参考法律正文；暂不纳入时在移动清单标明差异                                       |

其余决策在对应模块方案中细化，不扩大既有私人任务/媒体管理范围，不伪造真实 Provider 验证结果。
