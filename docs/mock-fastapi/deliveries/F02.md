# F02 管理导航与权限展示基础

状态：管理端基础导航与会话保护已实现，F02 全功能未完成；服务端导航接口和本地独立分支/提交受当前环境权限阻塞。

## 技术方案

见 [07-f02-admin-shell.md](../07-f02-admin-shell.md)。管理端维护编译期白名单并预留 `/api/v1/admin/routes` 动态目录接口；路径/名称/图标/权限需一致。仅 404/501 回退基础导航，空目录及 403 不启用回退权限。

## 当前实现

- 管理端新增 `src/services/admin-routes.ts`，定义 DTO、静态回退目录和结构归一化。
- 新增 `src/stores/admin-routes.ts`，负责一次加载、失败回退、退出清理和远程目录状态。
- 侧栏由导航 store 驱动，图标使用编译期白名单映射，数据库不能指定任意组件。
- 路由守卫在管理员会话有效后加载目录；未知路径进入受控 404。
- 不加载普通用户路由，不把客户端普通用户 token 当管理员权限。
- 未完成服务端 `/admin/routes` 控制器，因此部署当前服务端时会显示“已使用基础导航”。
- 会话版本保护登录/刷新/身份检查，导航版本保护目录加载；退出不会被迟到响应恢复，并发请求合并。
- 网络和 5xx 进入可重试的连接异常页面；远程目录不可访问的已注册页面进入 403。
- 登录跳转限定已注册页面，表单防重复提交并清除敏感输入。
