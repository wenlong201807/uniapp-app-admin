# 管理端 RBAC 与系统管理交付记录

更新：2026-10-15。代码位于当前工作区，未提交、未推送；已有运行中 Docker/HTTPS 服务未替换。迁移和真实接口在独立新建 MySQL 数据库与隔离 Redis 逻辑库验收。

## 已实现

- 独立管理员登录、刷新、退出、角色授权；access token 在内存，refresh token 在当前标签页 sessionStorage，关闭标签页结束恢复能力。
- 角色创建、编辑、启停、受控删除；内置 SUPER_ADMIN 不可修改/停用/删除。未知权限拒绝、禁止授予自身未拥有权限，组织数据范围只由超级管理员授予。
- 管理员创建、角色/部门/多岗位分配、启停；最后一个启用超级管理员不能移除。权限变更提升 authVersion，旧 access/refresh 会话失效。
- 部门树、名称/状态筛选、负责人/联系方式、排序、移动、启停、受控删除；同级规范名称唯一、最多 32 层、防环、启用祖先与在用约束。数据库锁覆盖多实例写入，revision 冲突返回 409；批量同级排序 API 原子更新。
- 岗位创建、编辑、启停、排序、受控删除；停用不新增分配，在用不能删除。
- 数据库菜单覆盖已编译页面的名称、排序和显示状态；路径/组件/图标/权限仍是编译期白名单，不能注入任意组件。菜单管理入口不能隐藏。
- 字典与参数创建、编辑、启停、删除；字典为唯一 value 的 label/value 数组，参数为普通字符串。配置由业务代码显式消费后才影响业务，不存凭证、不自动覆盖运行环境。
- 应用用户分页查询、部门筛选/分配与撤销全部会话；不提供删除私人任务/媒体的隐式级联操作。
- 首页从真实接口读取用户/任务/完成任务/媒体/管理员/角色/部门/岗位计数；按可见导航展示入口。
- 组织管理操作事务内审计，复用现有安全事件查询/导出；不记录密码、token 或配置值。

## 数据范围与权限边界

角色目前为每管理员单角色，策略包括 ALL、DEPARTMENT、DEPARTMENT_AND_CHILDREN、SELF、CUSTOM_DEPARTMENTS。管理员列表/编辑、用户列表/部门修改/撤销会话、部门查询及首页用户/任务/媒体计数应用相同范围。独立管理员身份不对应普通 User，SELF 下只能看到自己管理员记录，不推定拥有普通用户数据。

组织结构/岗位维护要求 ALL 范围；岗位、角色、菜单、参数是全局元数据，按各自功能权限访问。旧媒体、会话、审计、硬件、AI 等全局管理接口要求对应功能权限和 ALL 范围，受限角色不能绕过数据范围使用旧接口。普通用户任务和媒体 owner 隔离保持原协议。

历史无角色管理员只在 `20261014000100_admin_rbac` 迁移中一次性回填；服务重启不会再次把刻意撤掉角色的管理员升为超级管理员。旧接口 Guard 正确处理 `/api/v1` 前缀。

顺序：`20261014000100_admin_rbac` → `20261015000100_admin_organization` → `20261015000200_admin_system` → `20261015000300_admin_data_scope`。

隔离库已成功运行全部 24 个迁移。实际业务数据库尚未应用本轮迁移；上线顺序应为备份、迁移、服务端、管理端。不要在旧 API 上启用新管理页面。回退应用时保留新增组织/RBAC 数据，不直接删表。
