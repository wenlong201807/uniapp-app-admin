# P3-01 本机传感器的管理边界

客户端提供显式、限时的手机放置、方向、旋转、磁场、接近和阅读光线检查；读数只供当前页面显示，停止/后台/离页即清空，不持久化或上传。本阶段没有可管理对象，不新增传感器 API、数据库记录、管理页、设备遥测或硬件成功率。管理员不能远程启动传感器或控制用户屏幕和音频。

Android 和 iOS 当前工程能力不同；鸿蒙原生适配、iOS CoreMotion 与三系统真机仍待办，iOS 环境光当前不支持。客户端检查、56 项测试及三平台资源构建通过，仅证明工程验证。服务端和管理端只更新文档。

完整场景、平台边界及验收项见 [阶段十七](../../uniapp-app-server/docs/phase-seventeen.md)。下一项为 P3-02 健康数据。
