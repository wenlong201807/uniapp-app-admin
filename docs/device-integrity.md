# P3-03 设备风险与人工复核

管理员在“设备风险”筛选用户邮箱/昵称及复核状态，查看平台证明状态和客户端 Root/越狱、调试、模拟器枚举线索，记录已阅/需跟进或删除报告。使用独立管理员鉴权，普通用户无权访问管理 API；操作审计保留报告编号/动作，无风险值或平台 Token。

所有报告始终“未验证 · 客户端报告”。阴性不证明安全，开发包/调试器可能产生正常线索，复核不会改变可信状态。当前观察模式不封禁账号、不修改登录/设备密钥；不显示虚构平台验证成功率。

App Attest、Play Integrity 和鸿蒙证明没有真实验证器，页面明确未接入。报告只关联账号，尚无可信手机/设备密钥关联。15 分钟显示陈旧，每用户最多十条、最长 30 天，到期列表隐藏、每小时清理；服务停止或故障时物理删除可能延迟，需要生产监控。删除报告不删除已有安全审计。

管理端检查、13 项测试与构建通过，真实 MySQL/Redis API 已验证鉴权、复核、删除审计和留存；新版 API 只在临时本机端口验收。平台凭据/验证器、原生包、三系统真机、多管理员角色与新版 Docker/HTTPS 保持 TODO。
