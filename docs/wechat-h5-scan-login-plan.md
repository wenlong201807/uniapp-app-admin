# H5 微信扫码登录技术方案（管理端）

## 1. 本期定位

本期管理端不提供管理员微信扫码登录。管理员继续使用现有邮箱密码登录、管理员 Session 和 RBAC；普通用户的微信身份由服务端关联，管理端仅提供受权限保护的查看能力。

这样可以保持管理员身份与普通用户身份隔离，避免把微信开放平台网站应用身份误当作管理员授权。

## 2. 管理端功能

在“用户管理”列表中增加微信关联信息只读展示：

- 是否已关联微信。
- 关联时间。
- 最近一次微信登录时间。
- 关联 provider（当前固定 `wechat`）。
- 不显示 `openid`、微信 access token、subjectHash 或任何可用于登录的凭据。

建议默认仅向拥有现有用户查看权限的管理员展示脱敏状态；不新增“解绑”按钮，不允许管理端代替用户绑定或更换微信身份。

## 3. API 设计

新增或扩展现有管理员用户查询接口，返回只读摘要：

```json
{
  "wechatIdentity": {
    "provider": "wechat",
    "bound": true,
    "createdAt": "2026-10-17T00:00:00.000Z",
    "lastUsedAt": "2026-10-17T00:00:00.000Z"
  }
}
```

未关联时返回 `wechatIdentity: null`。服务端根据管理员的 data scope 过滤用户，不能通过 query 参数绕过部门或角色范围。接口不返回 `subjectHash`、原始 `openid`、微信授权 code、provider access token 或微信昵称头像。

如果采用列表查询，使用批量计数/关联查询，避免 N+1；本期仅扩展现有列表接口。响应继续遵循管理端现有 `{ data }` 协议和错误处理。

## 4. 前端改造

- 用户列表增加“微信登录”列：`已关联` / `未关联`。
- 用户列表增加关联时间和最近登录时间。
- 加载失败沿用现有 Element Plus 错误提示。
- 无权限时不渲染字段或操作入口，不能仅依赖前端隐藏；服务端必须验证管理员权限。
- 管理端登录页不增加微信按钮。

## 5. 审计与安全

- 查看微信关联摘要记录现有管理员审计事件（若当前用户查询已有审计策略则复用，不单独记录敏感身份值）。
- 管理端前端禁止把微信信息写入 URL、localStorage 或日志。
- 任何未来的解绑能力必须放在普通用户安全设置中，并要求密码/二次验证；本期不实现。

## 6. 验收标准

- 普通用户首次微信扫码创建后，管理端能看到“已关联”。
- 普通用户再次扫码后“最近一次登录时间”更新。
- 未关联用户显示“未关联”。
- 越权管理员无法读取不在 data scope 内的用户关联状态。
- 管理员仍只能通过现有管理员邮箱密码登录，普通用户 access token 不能访问管理端接口。

## 7. 实现位置

`src/services/admin-system.ts` 增加 `WechatIdentitySummary` 类型，`src/views/UsersView.vue` 显示关联状态、关联时间和最近登录时间。占位邮箱显示“未设置”。接口沿用 `GET /api/v1/admin/system/users`、现有管理员权限和部门范围，不新增接口或身份操作。未配置微信的环境，既有普通用户显示“未关联”。
